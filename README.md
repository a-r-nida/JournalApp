# Journal App

A secure and intelligent journaling platform that allows users to write journal entries, analyze emotional tone through NLP, and track their mental well-being over time.

## Tech Stack

- **Backend**: Spring Boot (Java)
- **Database**: MongoDB
- **Caching**: Redis
- **Authentication**: JWT (JSON Web Tokens)
- **Authorization**: Role-Based Access Control
- **Sentiment Analysis**: Natural Language Processing (NLP)
- **Code Quality**: SonarQube

---

## Features

- **Personal Journal Entries**: Create, update, and delete entries with timestamps.
- **JWT-Based Authentication**: Secure login and registration flow with access tokens.
- **Role-Based Access Control**: Admin and User roles with restricted endpoints.
- **Sentiment Analysis**: NLP-based mood prediction from user journal content.
- **MongoDB & Redis Integration**: Optimized storage and fast access with caching.
- **Code Quality**: Continuous inspection using SonarQube for maintainability.
